# Instrucciones del proyecto QualityLite

El usuario pidió que cada modificación se envíe a GitHub. Al finalizar cada cambio autorizado y verificado, registrar el cambio en un commit y sincronizarlo con `https://github.com/mariogonzalez-890918/QUALITY__MGLEZ.git`. Confirmar al usuario el resultado real de la subida. No afirmar que se subió si solo se modificaron archivos locales.

Esta carpeta es el proyecto QualityLite; las carpetas vecinas pertenecen a otros proyectos. No incluirlas. Conservar cambios remotos del usuario, no usar force push. Si Git local no dispone de autenticación, usar el conector GitHub autenticado.

Nunca subir base de datos de producción, archivos de evidencias, contraseñas, tokens iniciales, secret.key, server.json de ejecución ni entornos virtuales. La base vacía de release es un entregable permitido. Los instaladores nuevos, fuentes, manuales y resultados de pruebas forman parte de la entrega.

No afirmar pruebas de instalación elevada, servicio, reinicio de Windows o LAN sin haberlas ejecutado. Utilizar la versión actual del instalador y conservar el directorio de datos al actualizar/desinstalar.
